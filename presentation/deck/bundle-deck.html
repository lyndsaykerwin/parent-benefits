5 · How Zetaris and Meterless were used
Sponsor technology

Take one away and Bundle stops working.

One SQL door over private and public data

SELECT item, recall_title
FROM v_purchase_items -- her photos
JOIN cpsc_recalls -- live feed
The Fact-Checker re-asks it for every number. The deal court's view has no family data.
Without it: no personal cards at all.

H-MEM: memory that grows

• Agents' notes to each other, every run
• Rules parents taught it, which the judge must cite
• A memory of each family: answers and every scanned item

Nightshift: AI switchboard

First choice for AI calls on our Mac; forwards to NVIDIA.
Without it: the court never learns.

Nemotron + vision models

• Vision reads gear labels and receipts
• Nemotron argues over fine print and explains results
• The live demo calls NVIDIA directly
Without it: no photo reading; the court falls back to a plain rule screen.
Not used: Meterless Scout Intent, Markovian, World Model. Nightshift runs only on the builder's Mac. Code: adapters/zetaris.ts · adapters/memory.ts · adapters/llm.ts · agents/recall.ts5
6 · What was unique
What was unique

Four ideas that make it more than a chatbot.

01 · Zetaris + NVIDIA

A photo becomes data

Snap a car-seat label or receipt. Vision AI turns it into rows (model, UPC, price) that Zetaris joins to live recall lists in one question.
Drawn test label: Britax seat → found on NHTSA recall 12C004000
02 · Meterless H-MEM

A family memory that grows

Every answer and every scanned item is remembered, so each new run knows more. Parents see it in plain words: "Has: City Stroller".
Account tab · "What we know about your family"
03 · Agent collaboration

Agents argue, check and learn

The court debates deals, a lawyer challenges benefits, the Fact-Checker sends wrong cards back. Parent reports become rules: run 1 approves a trap, run 2 blocks it.
Learning test: run 2 blocks the trap, citing the rule (mem-28)
04 · A dataset the agents build

Graded deals become an API

Each graded deal is saved with its catches, with no family data. The app reuses it for every family, and a public API reports catch rates by store. A product we could sell.
GET /api/offer-audit?store=Amazon
