Meterless H-MEM · it learns

Run 2 is smarter than run 1.

Court approves a "free" membership

confidence: 0.8

Run 2

Judge cites mem-1 and blocks the same offer

Same code. New outcome, from memory.

Stored and loaded

Relevant rulings are pulled into the Judge's instructions before it rules. Memory nobody reads is decoration.

Confidence that moves

Each rule carries its source and a confidence score (0.8 for mem-1).

Audit trail

Every memory call is one line in the trace. Run 1, approval and run 2 traces ship in the repo.
